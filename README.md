# TwilightKitsUI

TwilightKitsUI is a Minecraft plugin that provides a user-friendly interface for players to browse and preview different kits. The plugin opens a UI with four distinct kits: Twilight Warrior, Twilight Archer, Twilight Mage, and Twilight Tank. Players can right-click on any kit to see the items included in it. This plugin is perfect for servers looking to enhance player engagement with a visually appealing and interactive kit system.

## Install

1. Download the TwilightKitsUI plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Ensure the plugin is installed and the server is running.
2. Players can open the Twilight Kits UI by typing `/kit` in the chat.
3. The UI will display four different kits: Twilight Warrior, Twilight Archer, Twilight Mage, and Twilight Tank.
4. Players can right-click on any kit to see the items included in it.
